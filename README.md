Wiring connections are provided only in lab2

Lab2.1
ESP32 A	         ESP32 B	
GPIO17 TX2	->   GPIO16 RX2	
GPIO16 RX2	->   GPIO17 TX2	
GND	        ->   GND

Lab2.2
ESP32 A	             ESP32 B
GPIO 17 TX	  ->     GPIO 16 RX
GPIO 16 RX	  ->     GPIO 17 TX
GND	          ->     GND

GPIO22 SCL    -> 	    GPIO22 SCL	
GND	          ->      GND
